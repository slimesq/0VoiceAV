# valgrind

Valgrind

# 编译安装valgrind

可以直接用该repo下的valgrind-3.15.0.tar.https://fossies.org下载比较慢。
```
wget https://fossies.org/linux/misc/valgrind-3.15.0.tar.bz2
tar -jxvf valgrind-3.15.0.tar.bz2
cd valgrind-3.15.0
./configure  
make  
sudo make install
```
